# Deterministic virtual booking evidence

The simulator uses a frozen `virtual-covered-call-v1` policy. All four independent weekly sleeves start with 10 virtual SOL including the predeclared uncovered reserve; premium never rolls into later weeks. Explicit season consent precedes the first voting roster. No wallet or provider authority is required for research, voting or simulation.

An internal source reader must commit the original snapshot before the fixed published booking timestamp (vote close). Exact version terms, source/provider/mode, quantity, minimum/increment, capacity, 60-second freshness, shorter quote expiry, opening/settlement fees and reserve are checked. Missing or late original input produces an immutable unranked holding record and a visibly unranked virtual allocation. It never retrospectively acquires a favorable quote. Known holding with a frozen snapshot books no option.

Synthetic complete-round PostgreSQL evidence covers two concurrent booking and settlement jobs, one premium/fill, exact fee/delivery accounting, no double-counted delivery cash, immutable snapshots, changed-settlement refusal, explicit consent/ownership, and no late enrollment. A mismatched UUID/text SQL parameter was exposed by the actual PostgreSQL test and fixed with explicit casts. Contract tests cover no live methods, capacity/size/staleness rejection, physical delivery and explicit observed USD/USDC conversion. Terminal source, exact expiration timestamp, exercise boundary and fee policy are frozen; unsupported cash settlement fails closed. USD is never assumed equal to USDC.

Verification: full `npm run verify` passes 84 units, typecheck/lint and web/worker builds; full contracts 16/16; full PostgreSQL 68/68 before the added late-consent case, then the final four-case simulation target passes. Full isolated Chromium 10/10 includes explicit unchecked/checked consent at 390/1360px. All fixtures are original synthetic teaching data, including deliberately restored prior states; none prove provider availability, executable liquidity or actual settlement.

Configured quote/terminal readers remain unavailable due to Task 0 rights/provider blockers. Their worker handlers fail explicitly; they cannot make up sources. Source-independent recovery books missing original data as unranked and retains settlement as pending. No live submission capability exists in the simulator. Real-source ranking and production settlement evidence remain separate release gates.
