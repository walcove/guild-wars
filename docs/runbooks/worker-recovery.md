# Worker delivery and recovery

Local setup: run application migrations, then `npm run db:worker:migrate:test` with the designated TEST_DATABASE_URL. The setup uses Graphile Worker 0.18.0 supported migrations; a distinct `guild_wars_worker` role owns only its queue schema/tables, following [Graphile ownership guidance](https://worker.graphile.org/docs/cli/run). The web runtime has no direct queue-table access; the bounded, search-path-fixed `gw_enqueue_job` security-definer wrapper delegates to the [documented SQL enqueue API](https://worker.graphile.org/docs/sql-add-job) in the current domain transaction. Application tables remain owned by the migrator. Local passwords are disposable test values only.

Start one persistent process with WORKER_DATABASE_URL, never a mainnet/provider key. Critical and background runners have separate pools capped at 2 and 3 connections, with 1 and 3 handlers respectively. Web is capped at 10. Queue names are finite. Ordinary network work must not retain a ballot/database lock. Startup and a library-scheduled minute sweep recover due ballot jobs; services still enforce deadlines independently. Domain-specific handlers are installed by subsequent tasks; missing handlers throw and retain retries instead of inventing results.

A library job key is a scheduling hint. Database-only effects use a committed application operation ID, making replay harmless after a handler/process failure. Telegram delivery moves through Pending → Sending → Published only when an acknowledged message reference is stored. A crash or ambiguous send is Unknown. Do not blindly resend it; reconcile or create an explicitly marked same-version replacement.

Pinned 0.18.0 automatically considers locks stale after four hours (`dist/sql/resetLockedAt.js`). Automatic scans are not immediate. Alert on overdue domain transitions and queue/reconciliation lag. After independently establishing a process is dead, an operator may use the supported `WorkerUtils.forceUnlockWorkers` API on its exact recorded worker ID. Never unlock a possibly live worker or directly update private Graphile tables. Our SIGKILL regression proves death, unlocks only that worker and verifies one committed effect after restart.

Local evidence: real PostgreSQL rollback/replay, ambiguous delivery, SIGKILL recovery, web-role enqueue and reserved-capacity tests. A saturated three-handler background queue did not starve a critical callback within its one-second test bound; this is local evidence, not a production throughput claim. Funded trades and production Telegram sends are absent from this harness.
